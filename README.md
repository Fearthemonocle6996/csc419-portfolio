## About

A responsive personal portfolio built from scratch with plain HTML, CSS and JavaScript. It includes an About Me section, a Projects section, a Call to Action, and a dedicated project details page.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Hero, About Me, Projects, Contact (call to action) |
| `project.html` | Full case study for the QuickBite project |

## Tech stack

- HTML5 with semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 with custom properties (variables), Flexbox and Grid, mobile-first media queries
- Vanilla JavaScript for the mobile menu

## Run locally

No build step is needed.

1. Clone the repository.
2. Open `index.html` in a browser.
