Project 01 / Case study

QuickBite

A cafeteria ordering app that replaces the counter queue with a few clicks.

Type
Desktop application
Built with
Java, JavaFX
Role
Developer
View source code

01 Full description

QuickBite is a JavaFX application for ordering food from a campus cafeteria. A student opens the app, browses the menu, adds items to an order, reviews the total and submits it. The cafeteria gets a clear list of what to prepare instead of a crowd shouting orders over a counter.

I built it as an object-oriented project, so menu items, orders and users are modelled as separate classes with clear responsibilities, and the interface is kept apart from the logic behind it.

02 The problem I solved

Cafeteria queues waste time at peak hours, and orders taken verbally get mixed up. Students want to know what is available and what it costs before they reach the front. QuickBite moves ordering onto a screen so the menu, the prices and the order total are visible up front and mistakes are easier to catch.

03 Features

  • Browse the cafeteria menu with item names and prices
  • Add and remove items from an order
  • Live order total as the order changes
  • Order summary before submitting
  • Desktop interface built with JavaFX

06 What I learned

  • How to structure a JavaFX application so the screens and the logic stay separate.
  • Why object-oriented design makes a project easier to extend and defend.
  • How much easier debugging is when each class does one job.
  • That a clear, simple interface matters more than extra features.
